# spine-segmentation

**Цель работы** - разработка системы анализа анатомических структур позвоночного столба на КТ-исследованиях, включающей этапы сегментации и идентификации позвонков.

**Задачи:**
- Анализ существующих методов сегментации 
медицинских изображений
- Разработка метода идентификации отдельных 
позвонков на КТ-снимках
- Экспериментальное исследование и оценка 
качества системы

Входные данные - трехмерные КТ-исследования формата NIfTI.
На выходе - трехмерная сегментационная маска из 26 классов (от шейных позвонков до первого крестцового).
**Метрики:** Dice и IoU.

**Данные:**
1089 исследований от Университетской клиники Базеля. Данные собирались на протяжении нескольких лет на разных томографах, с разными протоколами сканирования, включают пациентов с патологиями, т.е. максимально разнородны.

**Предобработка:**
Не все исходные исследования корректны, поэтому была проведена ручная фильтрация, по итогам которого было отобрано 929 снимков (были удалены исследования с ошибками разметки, с артефактами и сильно обрезанные снимки без позвоночника). 
Также была проведена автоматическая предобработка:
- масштабирование до 256^3
- ограничение HU до [-1000, 800]
- минимаксная нормализация
- аугментация

**Прямой (одноэтапный) подход** показал плохие результаты (IoU = 0.22) из-за дисбаланса классов. В работе предложен и реализован двухэтапный пайплайн.

**Этап 1: Бинарная сегментация (поиск локализации позвоночника)**
Архитектура: 3D U-Net (энкодер: EfficientNet-B2, предобученный на ImageNet)
Вход: 1 канал (КТ-снимок)
Выход: Бинарная маска (позвоночник / фон)
Лосс: Dice Loss + BCE (вес позвоночника = 10)

**Подготовка ко второму этапу: выделение области интереса**
По бинарной маске вычисляется минимальный ограничивающий параллелепипед.
КТ-снимок и бинарная маска обрезаются по его границам с небольшим отступом для сохранения контекста окружающих тканей.
Это позволяет убрать ненужный фон и уменьшить дисбаланс классов.

**Этап 3: Многоклассовая сегментация (идентификация позвонков)**
Архитектура: 3D U-Net (энкодер: EfficientNet-B2)
Вход: 2 канала (обрезаный КТ-снимок + обрезанная бинарная маска из 1 этапа)
Выход: 26 классов (C1-C7, T1-T12, L1-L5, S1, Фон)
Лосс: Dice Loss + CE (веса классов от 321 до 1908, обратно пропорционально их частоте).
Оптимизация: AdamW + ReduceLROnPlateau.


**Перспективы развития:**
- Улучшение качества сегментации шейного отдела.
- Модуль автоматического выделения патологий по геометрическим характеристикам позвонков.
- Интеграция в клинический процесс: веб-сервис или приложение.
